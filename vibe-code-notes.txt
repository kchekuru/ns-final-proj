Checklist
- Use Python environment from repo (.venv) and install exact dependencies from requirements.txt
- Keep models as-is for baseline parity (especially Models/kitsune.h5)
- Use repository-relative paths only (../Data, ../Models)
- Generate / verify TP-FN-FP case artifacts before explanation pass
- Keep script and notebook outputs aligned to avoid drift
- Capture final table numbers after one clean rerun
